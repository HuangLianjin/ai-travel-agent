# 星旅 Agent 生产化升级计划书

> 版本：v3.0
> 日期：2026-08-21
> 目标：从“个人高完成度项目”升级为“可真实上线运营的产品”

## 1. 现状与目标

| 缺口 | 现状 | 升级目标 |
|---|---|---|
| 上线地址 | 仅本地 127.0.0.1:8000 | 云服务器 + HTTPS 在线地址 |
| 真实用户 | 只有演示账号和测试账号 | 100+ 内测用户、注册/验证/反馈闭环 |
| 存储 | SQLite 单机文件 | PostgreSQL + 自动备份 |

## 3. P0：上线地基

### 3.1 真实上线地址

方案：云服务器 + Docker + Nginx + HTTPS

```text
1. GitHub 仓库：https://github.com/你的用户名/ai-travel-agent
2. 云服务器：腾讯云/阿里云/华为云 2C4G
3. docker compose up -d --build
4. Nginx 反代 127.0.0.1:8000
5. certbot 配 HTTPS
6. CORS_ORIGINS=https://travel.你的域名.com
```

验收：

- 在线地址可访问
- HTTPS 正常
- 健康检查 `/api/health` 返回 200
- 重启后数据不丢

### 3.2 SQLite 升级 PostgreSQL

当前 `app/db.py` 直接使用 sqlite3，改造成本最高，分三步：

```text
第一步：抽出 Storage 接口
  新增 app/storage/base.py
  定义 init/query/execute/migrate

第二步：PostgreSQL 实现
  新增 app/storage/postgres.py
  使用 psycopg 或 SQLAlchemy
  保留 SQLite 作为本地开发模式

第三步：数据迁移
  编写 scripts/migrate_sqlite_to_postgres.py
  把 users/trips/conversations/guides/reviews/agent_runs 全量迁移
  迁移前备份 SQLite，迁移后做行数对比
```

推荐：

- 内测：Neon 免费 PostgreSQL
- 正式：云数据库 PostgreSQL（腾讯云/阿里云/RDS）

验收：

- 所有接口在 PostgreSQL 模式下通过
- 迁移后行数一致
- SQLite 模式仍可作为本地开发回退

### 3.3 备份

```text
每天 3 次 pg_dump
保留 14 天
备份到对象存储/另一台服务器
每月一次恢复演练
```

### 3.4 搜索和 LLM 付费

```text
搜索：
  Tavily 付费或 SerpAPI 付费
  保留多 Provider 自动降级
  单用户每日配额：20 次
  成本告警：月消耗超过阈值自动通知

LLM：
  DeepSeek 充值到生产账号
  用户每日 Token 配额
  行程缓存：同城市同参数 7 天复用
  模型分级：普通用户用便宜模型，会员用更强模型
```

验收：

- 单次行程成本 <= 1 元
- 每日额度自动限制
- 成本报表可看

## 4. P1：账号安全与合规

### 4.1 邮箱验证

```text
1. 注册时生成 6 位验证码
2. 发送验证邮件（SMTP/Resend）
3. 验证通过后账号才能登录
4. 支持忘记密码、重置密码
5. JWT 增加 refresh token，access token 30 分钟
```

### 4.2 内容审核

```text
文本：
  敏感词库 + 违规文本检测
  攻略/评论发布前先过审

图片：
  接入阿里云内容安全/腾讯云天御
  头像、攻略图片自动审核

举报：
  用户可举报攻略/评论
  举报进入管理员队列
  封禁/拉黑/删除联动
```

### 4.3 隐私与合规

```text
1. 用户协议
2. 隐私政策
3. 账号注销
4. 数据导出
5. 登录日志与操作审计
6. 未成年人保护
7. 外部 API 数据来源声明
```

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| PostgreSQL 改造工作量大 | 先抽 Storage 接口，再迁移，SQLite 保留 |
| 国内支付需要资质 | 先做会员，不做实际交易，或走海外 Stripe |
| 内容审核成本高 | 先做敏感词 + 人工复核，再接入云审核 |
| 真实用户少 | 小规模种子用户 + 反馈闭环 |
| API 成本不可控 | 用户配额 + 缓存 + 成本告警 |
